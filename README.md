## ✨ Features

- 🎮 **One-Click Server Setup** - Install Paper servers in seconds
- 🔌 **Plugin Marketplace** - Browse and install plugins from Modrinth
- 💻 **Live Console** - Real-time server logs with command execution
- 👥 **Player Management** - Kick, ban, op players with one click
- ⚙️ **Visual Configuration** - Edit server.properties with a beautiful GUI
- 🌍 **Multi-Server Support** - Manage unlimited servers from one interface
- 🌐 **Playit.gg Integration** - Free port forwarding built-in
- 🔔 **Desktop Notifications** - Get notified of important events
- 🎨 **Modern Dark UI** - Beautiful interface with smooth animations
- 🔄 **Auto-Update Checker** - Stay up to date with the latest version

## 📋 Requirements

- **Windows:** Windows 10/11 (64-bit)
- **Linux:** Any modern distribution
- **Java:** 17 or higher ([Download Java](https://adoptium.net/temurin/releases/))
- **RAM:** 4GB minimum (8GB+ recommended)
- **Storage:** 500MB for app + space for servers

## 🚀 Quick Start

1. **Download** the installer for your platform
2. **Install** and launch OmniManager
3. **Create** your first server with the + button
4. **Install** Paper server software
5. **Start** your server and play!

## 🛠️ Development

### Prerequisites
- Node.js 16+
- npm or yarn

### Setup
```bash
# Clone the repository
git clone https://github.com/omninodes/omnimanager.git
cd omnimanager

# Install dependencies
npm install

# Run in development mode
npm start
```

### Building
```bash
# Build for Windows
npm run build:win

# Build for Linux
npm run build:linux

# Build for both
npm run build:all
```
